# Well Edge Cutting Tools

A modern, animated marketing website for **Well Edge Cutting Tools**, built with React and Vite. Features smooth scroll interactions, motion-driven UI, and a fully responsive layout to showcase products and services.

🔗 **Live Site:** [Add your deployed link here]

## ✨ Features

- ⚡ Fast, modern build powered by Vite
- 🎨 Responsive UI styled with Tailwind CSS
- 🎬 Smooth animations using Framer Motion & GSAP
- 🖱️ Buttery-smooth scrolling with Lenis
- 🧭 Client-side routing with React Router
- 👁️ Scroll-triggered reveals via React Intersection Observer
- 🎯 Clean icon set with Lucide React & React Icons

## 📦 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/swaran526/welledgecuttingtools.git

# Navigate into the project directory
cd welledgecuttingtools

# Install dependencies
npm install
```

### Development

```bash
npm run dev
```

This starts the local development server (Vite). Open the printed local URL in your browser to view the site.

### Build for Production

```bash
npm run build
```

Generates an optimized production build.

### Preview Production Build

```bash
npm run preview
```

### Linting

```bash
npm run lint
```
